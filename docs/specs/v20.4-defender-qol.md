# Siegeline: Defender Quality-of-Life Spec

Two features to make defending easier to learn and less punishing: **Auto-Maze** and **Remove & Inspect** (bridge preview), backed by a general **Undo** system.

## 1. Auto-Maze

### Problem

New defenders find it intimidating to design a maze and place towers in the first wave, especially now that waves have a time limit.

### Behaviour

- A new **Auto-Maze** button, next to the existing Auto-Tune button.
- When clicked, it spends a budget on walls, placed to make the enemy path as long as practical.
- **Add-only:** it never moves or removes existing walls or towers. It builds around whatever is already on the board.
- Tower placement stays fully with the player.
- Aim for "good enough," not optimal. It's a starter, like Auto-Tune. The real skill is in refining the maze.
- It extends the existing 3–4 block path-extension suggestion feature to its natural extreme.

### Budget

- **Wave 1:** a fixed amount. The defender starts with 300 coins, and four vanilla towers cost about 180. The budget must leave room for at least four towers plus a few customisations. Set to **60 coins**.
- **Later waves:** a percentage of leftover budget (value TBD through playtesting).

### Undo

- One Ctrl+Z (or the Undo button) right after Auto-Maze removes the whole auto-generated maze and refunds its cost. Players can preview what it comes up with and go back to a blank slate risk-free.

## 2. Remove & Inspect (Bridge Preview)

### Problem

One missed weak wall can cost the defender the game when the attacker bridges it. Today, defenders have to imagine in their heads how the path would reroute.

### Approach

Repurpose the existing **Remove** card and rename it **Remove & Inspect**. No new screen, no new interface, no extra buttons. Removing a wall and bridging it change the path in the same way, so the preview fits naturally inside this tool.

### Interactions (with Remove & Inspect selected)

| Action | Result |
| --- | --- |
| Hover over a wall | Current path stays in its normal colour. The rerouted path, as if that wall were gone, appears instantly in a bright highlight colour (yellow or red), with a tile delta, e.g. "−14 tiles." |
| Click a wall / click-and-swipe | Removes walls (current behaviour). Swiping **skips towers**. |
| Click-and-drag a tower | Moves the tower. No deletion. |
| Single click on a tower | Removes the tower and shows a prominent **"Tower removed — Undo"** pop-up. |

### Details

- **Drag threshold:** a few pixels of movement before a press counts as a drag, so slightly shaky clicks don't misfire.
- The preview is intentional: it only shows when the defender actively hovers with this tool. No automatic risk heatmap. The defender still has to review walls and decide for themselves.
- **Discovery:** the card name hints at the inspect function. Show a one-line tooltip the first time the card is selected: "Hover walls to preview bridge risk."

## 3. Undo System

- **Ctrl+Z** and an on-screen **Undo button** both undo the last action (tower removal, wall removal, Auto-Maze, and so on).
- Undo restores the exact prior state, including tower upgrades and customisations, and reverses any refund or spend, so it can't be used to exploit the economy.
- Undo is unavailable once a wave starts. No undoing during combat.

## Open Questions

- Auto-Maze percentage of leftover budget for later waves.
- Highlight colour for the preview path (yellow vs red).
- Undo depth: last action only, or a multi-step history?
- Should the attacker get any equivalent preview when choosing where to bridge?
